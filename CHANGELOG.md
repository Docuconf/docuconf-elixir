# Changelog

All notable changes to docuconf for Elixir are documented here. Entries after 0.1.0 are generated by
[release-please](https://github.com/googleapis/release-please) from Conventional Commit messages; see
[CONTRIBUTING.md](CONTRIBUTING.md).

## 0.1.0

First version: typed configuration contracts for Elixir applications, implementing spec `v1alpha1`. No runtime
dependencies.

### Features

* One declaration, in the NimbleOptions style, of every environment variable and file the app reads, used from
  `config/runtime.exs`, with types, constraints (including `item_min`/`item_max`), descriptions and secrets.
* Validation at boot that reports every problem together with stable error codes and writes the report to
  `/dev/termination-log`; RE2-compatible patterns.
* Boot checks for files: JSON/YAML/TOML config against a JSON Schema, TLS key pairs, CA bundles, PKCS#12/JKS
  keystores, text and binary files; `reload: watch` with `Docuconf.Watcher`.
* `mix docuconf.export`, contract-first mode and the shared conformance runner.
* The `orders` example service.
